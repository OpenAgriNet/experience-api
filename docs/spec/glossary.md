# Glossary

- **Turn**: one user message plus the conversation before it.
- **Answer**: the outcome, the content blocks (text or refusal), the sources, and maybe an error.
- **Citation**: links a source to a span of a text block.
- **Delta**: one piece of answer text, sent as it is written.
- **Completed**: the final event; it holds the whole answer and replaces the deltas.
- **Trace id**: the DSS's name for one attempt; the client shows it when something goes wrong.
- **DSS**: the Decision Support System, which writes the answers.
